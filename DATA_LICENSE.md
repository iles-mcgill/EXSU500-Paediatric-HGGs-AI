# BraTS-PEDs dataset licence and attribution

## Scope

The external BraTS-PEDs dataset (Version 1, 2025) is distributed by The Cancer Imaging Archive (TCIA) under [Creative Commons Attribution 4.0 International (CC BY 4.0)](https://creativecommons.org/licenses/by/4.0/); the [legal code](https://creativecommons.org/licenses/by/4.0/legalcode) contains the full terms.

This notice applies to the dataset, not to code or documentation authored for this repository. No repository-wide code licence has been selected here; adding this notice does not grant an MIT, Apache, or CC licence to the team's code.

## Source and usage

- [Official TCIA collection and download page](https://www.cancerimagingarchive.net/collection/brats-peds/)
- [Persistent dataset DOI: 10.7937/DX5C-TJ86](https://doi.org/10.7937/DX5C-TJ86)
- [TCIA Data Usage Policies and Restrictions](https://www.cancerimagingarchive.net/data-usage-policies-and-restrictions/)

Provide attribution and the licence link, and indicate any changes when sharing adapted data, in accordance with CC BY 4.0. Follow the collection's citation requirements. Obtain images directly from TCIA; this repository does not redistribute them.
